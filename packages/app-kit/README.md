# @business-os/app-kit

What the three Expo apps share: the API client, Supabase, the design tokens and brand colors,
the basic components (button, field, card, screen) and the providers for theme, language and
sign-in. App-specific providers (the business, the MyBiz team) stay in each app.

Imported as `@business-os/app-kit/lib/api`, `@business-os/app-kit/components/ui`, and so on.
