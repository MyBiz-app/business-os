## How to take them

1. Seed the demo data (Actions, "Seed staging demo data", `demo=curated`) and sign in with the
   demo client and owner.
2. Open the app (the web build from `deploy-apps-web.yml`, or locally with Expo) in a browser
   window of the sizes above, or use the iOS simulator and Android emulator for real device frames.
3. Check each image for real personal data: demo names only.
4. Store originals under `/mnt/project-files/store-screenshots/` (not in git: they are large).
